# Android build notes

This folder contains a basic Android app starter for UTAR WiFi Helper.

## Build an APK
1. Install Android Studio.
2. Open this folder as an Android project.
3. Select Build > Generate Signed Bundle / APK.
4. Choose APK.
5. Build and install it on a phone.

## Install on phone
1. Copy the generated APK to the phone.
2. Open it and tap Install.
3. If prompted, allow installation from unknown sources.
